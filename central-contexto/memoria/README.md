# Memória — estrutura de pastas

Use esta pasta para guardar conhecimento de longo prazo, aprendizado recorrente, referências técnicas e cruzamentos de contexto que podem ser úteis em mais de uma sessão.

Não coloque aqui dados transitórios (pendências, estado corrente do projeto). Isso fica em `../pendencias/` e `../projetos/`.

## O que vai aqui

- Dicionários de dados e KPIs
- Decisões consolidadas com motivo
- Documentos de referência do negócio (não código)
- Rascunhos de documentos que ainda não têm lugar definido

## O que NÃO vai aqui

- Estado atual do sprint ou da tarefa
- Checklist de algo que já está em andamento
- Resultado de uma única sessão sem valor futuro

## Convensão de nomes

- `NN_DESC.md` — descritivo, ex: `01_dados_clientes.md`
- `LOG_DECISOES.md` — registro cronológico de decisões
- `PROMPT_MESTRE.md` — prompt base de trabalho se houver
